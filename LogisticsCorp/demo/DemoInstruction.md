# DemoInstruction.md

This file provides guidance on the specifications for a LogisticsCrop demo page.

## File location and content

All files for this demo must be inside a separate folder in the root dir of the project. Folder should be named "demo".
The folder can contain only .html, .css and .js files.

## Technical specifications

Since this is a demo, there is no functionality required. Just purely design and aesthetic. 
The design should be responsive and look good on smaller devices as well.
No bootstrap classes for the styling of elements - just css.

## Design specifications

Dark mode theme with a yellow primary color.
Must adhere to proper contrast standards.
The design should be modern and sleek, with an air of professionalism. Only very slight amounts of flashiness allowed (in very specific areas only).
Make sure the design is consistent - establish clear color patterns, consistent spacing between elements and section, and font-sizes.
Using the application should be feel sharp, yet still give the user good indication and visual guidance of what they are doing.

## Demo contents

The demo page should include a navigation menu.
Space for the company logo (no need for an actual image, just mark the space where the image would be).
User profile section.
The main content of the page - a 'Shipment History' page where the user can view the history of any given shipment, either ordered from them or for them. You can refer to the ShipmentHistory.cs and Shipment.cs to see what kind of data is contained in those classes that needs to be visualized here. There should be an option to view a different one of the user's shipments.
